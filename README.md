# Jobscraper
**Консольный скрипт для парсинга вакансий с hh**. Скрипт работает автономно в терминале сканируя целевой сайт по заданным фильтрам и интервалу, сохраняет найденные вакансии в .csv и .json файлах.

## Возможности
*  **Поиск по нескольким параметрам** для этого нужно указать в файле config.yaml ключевые слова:
   *   scraper:
      *  - "https://hh.ru/search/vacancy?text=фильтр1"
      *  - "https://hh.ru/search/vacancy?text=фильтр2" ...
*  **Подключение через прокси** по-умолчанию включено.
*  **Самовосстановление** при потере соединения скрипт ожидает восстановления сети не завершая свою работу.
